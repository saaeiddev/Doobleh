# Doobleh — The Eternal Voices

Doobleh is an immersive cinematic digital museum celebrating Iranian dubbing artists, voice acting and the cultural memory of Persian dubbing.

## Stack
- Next.js 15 / React 19 / TypeScript
- React Three Fiber + Drei
- Framer Motion + GSAP
- Static export for GitHub Pages

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Artist bios, portraits and dubbing credits are stored with source URLs. The project deliberately avoids invented credits and AI-generated artist portraits. When a reusable real portrait is not yet verified, the UI shows a typographic identity panel instead of a fake face.
